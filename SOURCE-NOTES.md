## Intentionally omitted
- The unrelated property-for-sale post
- Temporary June discount/promo copy
- Scraper-contaminated personal chat content
- "Open now" because it is a scrape-time status, not a stable business-hours statement
- Exact current prices, because rates can change and the public site should direct visitors to the resort for current pricing
- Exact capacities in public copy even though rate cards show group-size brackets; this avoids presenting potentially stale package limits as permanent facts

## Brand asset note
The source pack contains Kavanagh branded cover/post artwork, but no clean standalone logo file. The UI uses a text wordmark inspired by the source palette and uses the supplied official cover artwork for social metadata. It does not claim the text wordmark is the official logo.
